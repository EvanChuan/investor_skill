# investor_skill - 專業投資人分析框架

## 專案簡介

investor_skill 是一套基於 30 年實戰投資經驗設計的七階段投資分析框架，
適合作為 AI Skill 載入，協助投資人系統性地從宏觀經濟到微觀個股進行全面評估，
做出更理性的投資決策。

## 七大分析模組

1. 總體經濟市場分析 (macro-market-analysis)
2. 產業研究與輪動 (industry-research)
3. 個股基本面分析 (equity-fundamental-analysis)
4. 估值分析 (valuation-analysis)
5. 市場情緒追蹤 (market-sentiment-tracking)
6. 技術面分析與時機 (technical-analysis)
7. 風險管理與執行紀律 (risk-management)

## 使用方式

將此 Skill 載入 AI 助手後，可使用如下指令：
  「請根據 risk-management Skill 幫我更新 2026 Q1 風險雷達」
  「請用 macro-market-analysis 分析目前台灣股市環境」
  「請用七階段框架分析台積電（2330.TW）」
