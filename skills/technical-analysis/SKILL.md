# 技術面分析與時機 (Technical Analysis & Timing)

## 架構說明

本模組為 professional-investor-analysis 框架的**第六階段**，定位為進出場時機優化工具。應在完成基本面分析（Stage 3-5）後執行，或在使用者需要判斷技術買賣點時獨立使用。

> ⚠️ 技術分析是輔助工具，不是主要依據。必須結合基本面判斷，避免純技術線型操作。

## Skill 目標

這個 Skill 協助 AI agent 完成以下任務：

1. 判斷標的的多空趨勢方向（短中長期）
2. 識別關鍵支撐壓力位置，提供具體價位參考
3. 解讀技術指標訊號（RSI、MACD、KD、布林通道）
4. 識別重要型態（頭肩頂底、雙重頂底、三角收斂）
5. 根據量價關係判斷行情可信度
6. 給出具體的建議進場價位、停損點與停利目標

## 使用情境（When to use）

當使用者提出以下類型需求時，應載入本 Skill：

- 「這支股票現在可以買嗎？技術面怎麼看？」
- 「支撐在哪裡？我應該在哪裡設停損？」
- 「目前是什麼趨勢？短中長期方向如何？」
- 「RSI/MACD 出現什麼訊號？」
- 「這個型態代表什麼意思？」
- 「最近量縮/量增，代表什麼？」

## 分析框架（四步驟）

### Step 1：趨勢判斷

**核心問題：多頭、空頭，還是盤整？**

1. **均線系統**
   - 短期：5MA、10MA、20MA（月線）
   - 中期：60MA（季線）、120MA（半年線）
   - 長期：240MA（年線）
   - 均線多頭排列（短均 > 中均 > 長均）→ 多頭趨勢
   - 均線空頭排列（短均 < 中均 < 長均）→ 空頭趨勢

2. **趨勢線判斷**
   - 上升趨勢：更高的高點（Higher High）＋ 更高的低點（Higher Low）
   - 下降趨勢：更低的高點（Lower High）＋ 更低的低點（Lower Low）
   - 盤整：高點低點無明顯方向

3. **輸出格式**
   - 短期趨勢：多/空/盤整 + 說明
   - 中期趨勢：多/空/盤整 + 說明
   - 長期趨勢：多/空/盤整 + 說明

### Step 2：支撐壓力分析

**核心問題：關鍵價位在哪裡？**

1. **支撐位來源**
   - 前低價位（近 3-12 個月低點）
   - 整數關卡（心理支撐）
   - 成交密集區（大量換手帶）
   - 均線支撐（20MA、60MA 等）
   - 前期盤整區下緣

2. **壓力位來源**
   - 前高價位（近 3-12 個月高點）
   - 整數關卡（心理壓力）
   - 成交密集區上緣
   - 均線壓力
   - 前期盤整區上緣

3. **輸出格式**
   - 近期關鍵支撐：強支撐 XXX 元，次支撐 XXX 元
   - 近期關鍵壓力：近壓 XXX 元，強壓 XXX 元
   - 目前股價位置：接近支撐/接近壓力/處於中間

### Step 3：技術指標解讀

**核心問題：指標發出什麼訊號？**

1. **RSI（相對強弱指數）**
   - 標準設定：14日RSI
   - RSI > 80：超買，注意回調風險
   - RSI 50-80：多頭區間，動能充足
   - RSI 20-50：空頭區間，動能偏弱
   - RSI < 20：超賣，可能出現反彈
   - 背離訊號：價創新高但RSI不創新高（頂背離，看跌）；價創新低但RSI不創新低（底背離，看漲）

2. **MACD（指數移動平均差異）**
   - 標準設定：12, 26, 9
   - MACD 黃金交叉（DIF 上穿 DEA）→ 買進訊號
   - MACD 死亡交叉（DIF 下穿 DEA）→ 賣出訊號
   - MACD 柱狀圖由負轉正 → 動能轉多
   - MACD 柱狀圖由正轉負 → 動能轉空
   - 背離訊號同 RSI

3. **KD 隨機指標**
   - 標準設定：9日
   - K > 80：超買
   - K < 20：超賣
   - 黃金交叉（K 上穿 D）+ 低位 → 買進訊號
   - 死亡交叉（K 下穿 D）+ 高位 → 賣出訊號

4. **布林通道（Bollinger Bands）**
   - 標準設定：20日，2倍標準差
   - 股價觸及下軌 + 縮量 → 可能止跌
   - 股價突破上軌 + 放量 → 強勢突破
   - 布林通道收縮 → 即將出現大波動
   - 布林通道擴張 → 趨勢行情進行中

5. **輸出格式**
   - RSI（14日）：XX → 訊號說明
   - MACD：多空交叉狀態、柱狀圖方向
   - KD：目前數值、最近交叉訊號
   - 布林通道：目前位置（上軌/中軌/下軌）、帶寬狀態

### Step 4：型態識別與量價分析

**核心問題：型態意味什麼？量能可信嗎？**

1. **常見反轉型態**
   - 頭肩頂：多轉空，突破頸線確認，目標 = 頸線 - 頭到頸線高度
   - 頭肩底（倒頭肩）：空轉多，突破頸線確認
   - 雙重頂（M頭）：多轉空，確認回測頸線後反彈失敗
   - 雙重底（W底）：空轉多，確認回測頸線後守住

2. **常見整理型態**
   - 上升三角：突破上軌 → 繼續上漲
   - 下降三角：跌破下軌 → 繼續下跌
   - 對稱三角（收斂）：向上突破為多，向下突破為空
   - 旗形/楔形：整理後繼續原趨勢

3. **量價關係**
   - 價漲量增：健康上漲，動能充足 ✅
   - 價漲量縮：上漲動能不足，注意 ⚠️
   - 價跌量增：賣壓大，小心繼續下跌 ❌
   - 價跌量縮：賣壓趨緩，可能止跌 ✅
   - 爆量長上影線：主力出貨訊號 ⚠️
   - 爆量長下影線：主力吸籌訊號 ✅

## 限制與注意事項

- 技術分析為**輔助工具**，不能取代基本面判斷
- 技術訊號需配合**整體市場環境**（Stage 1 總體分析結果）
- 歷史型態不保證未來表現，重要關卡突破需**確認收盤**
- 本 Skill 不提供即時報價，需使用者提供當前股價或圖表資訊
- 分析基於使用者提供的價格水位，如有最新數據請以最新為準
