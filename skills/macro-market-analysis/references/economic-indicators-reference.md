# 完整數據指標總表（v2.3）

> 依時效性（短期/中期/長期）與領先/同步/落後屬性分類，供分析時按需取用。

## 屬性說明

- **短期指標**：週度/月度更新，反應即時市場狀態
- **中期指標**：月度/季度更新，判斷趨勢變化
- **長期指標**：季度/年度更新，確認週期位置
- **領先指標**：預測未來 3-12 個月經濟方向
- **同步指標**：反應當前經濟狀態
- **落後指標**：確認已發生的週期轉折

> **💡 淨流動性公式：**
> ```
> 淨流動性 = Fed 資產負債表總規模 - TGA（財政部現金餘額）- RRP（逆回購餘額）
> ```
> - 淨流動性 **上升** → 市場資金充裕，利多風險資產（股票、加密貨幣）
> - 淨流動性 **下降** → 流動性收緊，利空風險資產，利多防禦性資產

## 快速執行節奏建議

### 每日掃描（5-10 分鐘）
```
□ 10Y 殖利率 + 實質利率變化
□ VIX 水準
□ TGA + RRP 流動性變化（淨流動性計算）
□ FRA-OIS / TED Spread（危機預警）
□ ETF 資金流異常
```

### 每週深度分析（週六，1-2 小時）
```
□ 初領/續領失業救濟金（週四發布）
□ 完整 16 大資產資金流追蹤
□ CFTC COT 報告解讀（週五發布）
□ M2 + 銀行準備金 + RRP + TGA 流動性矩陣
□ ISM PMI（月初發布時）
```

### 每月全面檢視（3-5 小時）
```
□ 完整經濟數據矩陣（GDP, CPI, PCE, 就業）
□ SLOOS 銀行放貸標準（季度）
□ Fed 政策立場評估
□ 產業輪動分析
□ 資產配置調整決策
```

### 每季策略規劃（Risk Radar 啟動）
```
□ 執行完整 Risk Radar 掃描（Step 10）
□ 流動性週期定位
□ 壓力型 vs 健康去通膨判斷
□ AI/半導體資本週期檢查
□ 產出季度策略報告
```
